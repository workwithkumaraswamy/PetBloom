Pain Point 02

The Home Emergency Panic Vacuum

Pet owners possess zero first-response medical grooming aids at home when minor cuts or abrasions occur.

This lack of immediate triage causes frantic, costly emergency clinic visits for minor nicks that take 15 seconds to seal.

Pain Point 03

Mainstream stores sell stamped, blunt plastic clippers that crush claw beds rather than shearing cleanly.

Topical balms frequently use petroleum distillates, synthetic fragrances, and artificial chemicals toxic to licking dogs.

System Architecture

End-to-End Secure Transactional & Operational Pipeline

Slide 08 / 12
Step 01
Client Frontend
React 18 SPA initiates cart checkout & applies promo code (BLOOM10).
→
Step 02
Express API Gateway
Validates JWT bearer token, verifies stock, and creates pending order.
→
Step 03
Razorpay Gateway
Generates official transaction order ID; opens secure customer checkout.
→
Step 04
HMAC Verification
Backend re-hashes payment response using secret key to prevent tampering.
→
Step 05
Order Fulfillment
Prisma mutates status to PAID, updates inventory, and notifies admin.

Security Architecture Protocols

  • Parametric Query Sanitization: Prisma ORM prevents all SQL injection vectors.
  • Password Protection: Salted bcryptjs hashing prevents rainbow table attacks.
  • Cryptographic Verification: Payment status is never updated based on client-side responses alone.

Operational Scalability

  • Stateless API: Node.js backend can be horizontally scaled behind a load balancer.
  • MySQL Enterprise Ready: Seamless migration from local dev SQLite to AWS RDS MySQL.
  • Admin Audit Trail: Every status mutation records timestamps and payment identifiers.
